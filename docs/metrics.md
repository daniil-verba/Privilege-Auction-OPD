Порядок вычислений:   
1. Базовые множители: Сначала вычисляются коэффициенты, зависящие от действий пользователя (Время, Попытки, Силы).   
2. Штраф: Вычисляется отдельно, только если есть просрочка.   
3. Бонус: Вычисляется надбавка за ранг задачи (формула требует уточнения).   
4. Итоговый балл: Собирается из базовой цены, бонуса и множителей, минус штраф.   
5. Аукцион: Для выставления задачи на торги вычисляются коэффициенты Спроса и    Редкости, которые формируют Начальную сумму.

**Итоговый балл**:   
*Входные данные*: Базовая цена, Бонус, Время (коэфф.), Силы, Коэфф. попыток, Штраф.   
*Выходные данные*: Итоговый балл (Тип данных: `?`).    
*Формула*: `Итоговый балл = Базовая цена + (Бонус * Время * Силы * Коэфф. попыток) - Штраф`   
*Пример расчета*: Базовая цена = 100, Бонус = 50 (предположительно), Время = 1.5, Силы = 2.5, Коэфф. попыток = 0.85, Штраф = 10.    
*Расчет*: `100 + (50 * 1.5 * 2.5 * 0.85) - 10 = 100 + 159.375 - 10 = 249.375`   


**Коэффициент времени**:   
*Входные данные*: Тплан, Тфакт.    
*Выходные данные*: Время (коэфф.) (Тип данных: `?`).    
*Формула*: `Время = min(3, Тплан / Тфакт)`    
*Пример расчета*: План = 10 часов, Факт = 5 часов. `min(3, 10/5) = 2.0`    
Ограничение не дает коэффициенту улететь в бесконечность (например, если Тфакт = 0).   
   
**Коэффициент попыток**:   
*Входные данные*: Попытки.   
*Выходные данные*: Коэфф. попыток (Тип данных: `?`).   
*Формула*: Коэфф. попыток = 1 - 0.15 * (Попытки - 1)   
*Пример расчета*: 3 попытки. `1 - 0.15 * (3 - 1) = 1 - 0.3 = 0.7.`   
   
**Силы**:   
*Входные данные*: Объем, Сложность, Риски.   
*Выходные данные*: Силы (Тип данных: `?`).   
*Формула*: `Силы = (0.2 * Объем) + (0.3 * Сложность) + (0.5 * Риски)`   
*Пример расчета*: Объем = 2, Сложность = 3, Риски = 4. `(0.2 * 2) + (0.3 * 3) + (0.5 * 4) = 0.4   + 0.9 + 2.0 = 3.3.` ==🟣(В PDF указано округление до десятых).==   

**Штраф**:   
*Входные данные*: Базовая цена, Тфакт, Тплан.   
*Выходные данные*: Штраф (Тип данных: `?`).   
*Условие*: Если Тфакт <= Тплан, то Штраф = 0. Иначе применяется формула.   
*Формула*: `Штраф = Базовая цена * min(0.9, sqrt((Тфакт - Тплан) / Тплан))`   
*Особенность*: Для задач ранга D применяется фиксированный штраф (10-20%) вместо формулы.   
*Пример расчета*: База = 100, План = 10, Факт = 15. `100 * min(0.9, sqrt((15-10)/10)) = 100 * min(0.9, sqrt(0.5)) = 100 * min(0.9, 0.707) = 100 * 0.707 = 70.7`.   

**Форс-мажор и переназначение** ==🟣(Уточнить)==:   
*Формула для заболевшего*: `Заболевший = Базовая цена * Прогресс%`   
*Формула для нового исполнителя*: `Новый = (1 - Прогресс%) * Итоговый балл * Множитель срочности`   
*Пример*: База = 100, Итог = 150, Прогресс = 50% (0.5), Срочность = 1.3.   
*Заболевший*: `100 * 0.5 = 50 баллов`.   
*Новый*: `(1 - 0.5) * 150 * 1.3 = 0.5 * 150 * 1.3 = 97.5 баллов.`    

**Аукцион (Начальная сумма):**   
*Формула спроса*: `Спрос = min(Число желающих / Число слотов, 3) + 1`   
*Формула редкости*: `Редкость = 1 + (1 / Число слотов)`    
*Итоговая формула*: `Начальная сумма = Себестоимость * Спрос * Редкость`    
*Пример расчета*: Себестоимость = 50. Желающих = 10, Слотов = 2.   
*Спрос*: `min(10/2, 3) + 1 = min(5, 3) + 1 = 4.0`   
*Редкость*: `1 + 1/2 = 1.5`    
*Начальная сумма*: `50 * 4.0 * 1.5 = 300`.

**Расчет Бонуса**:  
*Входные данные*: Ранг задачи, Базовая цена.   
*Выходные данные*: Бонус (Тип данных: `?`), Множитель Ранга (M).   
*Логика*: В зависимости от выбранного ранга задачи, системе присваивается Множитель (M). ==🟣(Прим.: точная формула вычисления переменной «Бонус» в коде требует уточнения)==

| Ранг задачи   | Базовая цена (примерно) | Множитель Ранга (M) | Описание                                                      |
| ------------- | ----------------------- | ------------------- | ------------------------------------------------------------- |
| D (Низший)    | до 50 баллов            | 1                   | Бытовая рутина, мелкие правки, ежедневные привычки.           |
| C (Средний)   | 51 – 200 баллов         | 3                   | Стандартные рабочие или учебные задачи на пару часов.         |
| B (Высокий)   | 201 – 500 баллов        | 5                   | Серьезные таски, требующие глубокого погружения на весь день. |
| A (Эпический) | от 501 баллов           | 10                  | Крупные проекты, отчеты, модули, над которыми работают днями. |
